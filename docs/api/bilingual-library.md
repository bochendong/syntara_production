# 讲义与题库双语切换

2026-10-26。基于已验收测试分支 `codex/staging-next` 的 `21cd0181`，任务分支为
`codex/lecture-language-switch`。

MAT102 的 24 份 Markdown 文档在讲义库显示为 12 个入口，按 01–12 排列。
配对依据是 `coverSlideJson.sourceSha256` 和语言，限同课程、同文档类型且每种语言
恰好一份的记录。同步接口把这两个字段投影为归档可保留的 tags；正文接口采用同样
的投影，已有本地列表即使更新时间未变也会更新 tags。没有删除或改写讲义正文。

阅读器 header 提供「中文 / English」，切换时保留章节序号（数量不同时限制在有效
范围），同时切换目录、正文和资源。加载失败保留当前文档并允许重试。讲义库会
搜索两个版本的标题，「接着读」采用最近一次阅读的语言及章节。

题库复用现有的一题多语 `publicContent.translations['zh-CN']` 格式；英文原文保留在
基础内容中。题库和做题页 header 都提供切换，题目 ID、题号、难度、评分及作答记录
共用，选择项按 ID 替换显示文字。切换不会重新初始化答案，单语题继续显示已有内容。
本改动不生成缺失的译文，也不凭相似标题合并独立题目。

验证：

- `pnpm verify:local`：格式、lint、根项目及 native 两份 TypeScript 配置通过。
- `pnpm --filter @syntara/native build` 通过；保留已有分块体积及混合导入提示。
- 双语讲义、题目本地化及浏览器鉴权/传输测试共 9 项通过。
- 本地浏览器使用独立 QA 账号和 IndexedDB 夹具验证：24→12、中文→第二节英文→中文、
  失败后保留正文并重试、重新打开最近语言/章节；选择题答案及证明题文本在切换时保留，
  题号和数量不变。390px 容器中的语言按钮可用。
- 本地 QA 入口源码已移除；QA 夹具及构建日志仅留在忽略的 `node_modules/.cache/`。
