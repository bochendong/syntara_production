## 操作步骤与证据

1. **启动与账号课程范围：通过。** 启动恢复已有聊天；单课程账号只显示该课程。将账号课程清空、保留本地旧缓存后，手机、平板和桌面均显示“账号下还没有课程”，仍能进入“我的”，不会恢复缓存聊天。

2. **逐层返回：通过。** 验证了资料编辑取消 → 我的、头像选择取消 → 我的、我的 → 抽屉 → 聊天，包含浏览器后退。新增/编辑安排的取消和后退先关闭编辑器，再由课程日历返回聊天；从总日历直接返回聊天。没有出现空白页。退出登录仅验证确认窗口取消，没有执行退出。

3. **总日历：通过。** 选择日期、上/下个月和“今天”正常；从总日历的 CSC148 安排进入 CSC148 对应日期。选择 MAT136 新增“手机验收安排”，保存后在总日历显示 MAT136 标记，重新载入后仍存在。同课程与跨课程入口都正常；取消课程选择不会退出日历。20 门课程的长名称可完整换行，列表可滚动，标题与取消始终可见。

4. **新版我的：通过。** 保存名字、签名、学校后重新打开及重载仍保留；未保存的编辑取消后不生效。回复强度在重开、重载后保持，侧栏背景开关可切换。跨课程记忆入口打开正确课程，返回聊天。小屏星图缩小后不再相互挤压；320 宽度实测前三项间距 8px，文档宽度 320px，无横向溢出。

## 本轮修复

| 问题 | 重现与影响 | 修改与复验 |

| 桌面空账号回退旧课程 | `?count=0` 保留缓存时，桌面恢复旧课程/聊天，手机显示空账号 | 统一账号课程筛选，显式空集合不回退缓存；三种布局复验，并增加启动回归 |
