日期：2026-10-29（America/Toronto）。这是[首轮盲测](./problem-import-agent-blind-test.md)的扩展，使用新题与新学科，而不是重复原 CSC108/MAT102 样本。

## 结果与覆盖范围

本轮从测试服 29 门课程的原始资料目录中选择 10 门课，以 16 份真实数据库原件和实际课程 context 构成独立资料包。三个新子 agent 均以 `fork_turns:"none"` 启动，不继承主对话，不读取仓库、技能、其他 agent 输出、网络或数据库；只看独立说明、分配给它的原 PDF/DOCX、章节/规范和 provenance。可使用通用本地提取、渲染和 Python 工具。

最终 **30 条新题记录**覆盖全部八种平台题型，**7 张原始条件图/表**完成真实解码、尺寸/哈希检查及逐张查看。全部记录通过实际服务端 parser 和测试服 HTTPS 只读预览，分成 14 份 manifest。没有调用 --apply，没有新增题目、笔记或学生作答。

## 本轮实际发现并修订的说明问题

1. **副作用样例不等于脚本。** 列表修改题的 unittest 正确，但原 sampleIO 写了赋值、多行调用与查看状态，真实预检报 SyntaxError。当前 runner 即使在 test-file 模式也会用 eval 验证 sampleIO。说明和校验器现在明确单表达式边界；agent 改为真实调用返回值及 explanation，副作用由 unittest 检验。另用返回 42 的正确修改实现做本地检查，确认没有因参考样例的 None 擅自增加返回值评分要求。
2. **错误实现也必须保留锁定区。** 一个反例直接改写锁定函数，被结构检查拒绝而未执行断言；这不能证明算法测试有效。说明要求只修改允许空位，agent 改成合法空位内的错误算法。真实预检随后通过。
3. **不要误判画图不受支持。** 初始说明没明确开放题可提交手写/图片，agent 将部分绘制题保守标为 blocked。核对当前作答 UI、answer.images schema、图片批改入口后补齐说明，再由 agent 重新准备化学与经济绘制题。保留真实构造目标，未换成识别题或“描述图”。旧 blocked 文件作为历史保留，新 reconciliation 区分已复测与未复测，不能继续把所有画图题说成不支持。
4. **历史后勤不是本平台操作。** 政治学活动的个人/小组情境、禁用工具要求保留，但不再要求学生向历史 Canvas 交卷。公开题面与私有评分描述同步，未新增过程评分或声称能核实实际小组参与。
5. **明确共用案例的题号区间。** 原件明确说 Questions 19–21 共用条件，可以保留原编号形成题组；仅相邻或同主题的不同题仍不能随意合并。原资料公式、期限、单位、语言和当时情境保留，不擅自更新金融数值或营销案例事实。
6. **字段长度仍要机器检查。** 一条政治学标签超出说明已规定的 30 字符；真实 parser 拒绝。agent 缩短标签并保留 sourceMeta 完整原文件名，同时在生成器补长度断言；没有改题目或答案绕过校验。
7. **图片体积和可用性是独立条件。** 校验器补充基本 raster/base64/MIME/尺寸、重复图 ID、本机路径和真实 HTTP 字节限制检查。说明明确导入最多 2,000,000 字节、预检最多 250,000 字节；100 题分批不等于按图片体积分批。完整像素仍由实际图像解码器及人工源图对照验收。

准备 agent 修订自己的产物，主执行端没有手改答案来“凑通过”。执行端只把真实服务器的 validatedDraft 原样替换、proof 放入 item.codePreflight，另存 manifest-ready.json。一次预检 429 由实际同时最多两个任务的限制引起；等待在途请求完成后用同一输入重试，未当作参考程序错误，也未改服务器限制。

## 校验层次

- 全部 30 条：实际 schema/content/code-readiness、本地新增图片/请求体检查、真实课程与章节的 HTTPS 只读预览；14 份预览均 createsNotebooks=0。
- 全部 7 张图：base64 完整解码，Pillow verify，真实像素尺寸/输出哈希核对，原件整页与最终裁图查看。化学保留键级/电荷/标号，曲线保留实心/空心点及端点，统计保留单位/图例，金融保留期限和百分比。
- 三个新函数：真实 staging 预检 valid/referencePassed/starterRejected/incorrectRejected 全部为 true；6 个公开、16 个私有 unittest，3 个空实现和 5 个算法错误实现被拒绝。包含 mutation 与 template/slots，不只测试纯返回值函数。
- 68 个额外正反断言：调用实际 evaluateNotebookNonCodeProblem，不调用模型、不创建作答。覆盖选择各选项/多选额外选择拒绝、化学带符号电荷、费用表、时间增量、区间/LaTeX 最终答案及错误答案。数学、金融、LP、化学连接/价电子和开放题参考另作来源与独立推导审查。
- 37 项通用回归通过；格式、lint、完整根类型检查及 git diff --check 通过。新增回归包括图像路径/MIME/像素尺寸、图片导致的请求超限、test-file 仍不能执行多语句 sampleIO。没有以源码文本检查代替上述实际预检与预览。

结构化 rubric 是存储与内容审查依据，不是所有判题路径都会逐项执行其权重的证明。当前部分文本/图片评分路径使用通用维度及参考答案/analysis；说明现已如实指出，关键验收条件完整写入参考。没有对主观题模型评分、图片判分或 rubric 权重作全覆盖效果保证；代码文档语义、风格与效率也不因功能测试通过就自动获得证明。

## 有证据的边界与未覆盖项

- COMM190 的原 Excel 题遮住 H5:H9 等关键区域，四个对应子项保留缺条件/待补原件状态；没有猜测被遮住的单元格或把原表地址抹掉。
- DSCI 的真实 R 补全 Q21 无当前受支持 runner，明确不进入导入 manifest；没有用 Python、code_token 或选择题代替实现目标。
- ECO 初选资料只有空网格和答案区手绘曲线，不能拿来凑“给定曲线读图题”；新增 TVC 表是真实给定数据，而需求曲线构造题允许学生自己绘图，二者不混称。
- 初期按旧 guide 误判为 blocked 的其他化学绘制任务，未自动宣布全部通过；以 reconciliation 记录历史原因、重新准备的具体范围及尚未复测范围。此项不等于现在平台没有画图能力。
- 本轮是 10 门真实课程的分层样本，不是 29 门课整库验收，也不声称覆盖数据库没有原件的每个学科或所有学科×题型的组合。原件目录、选取理由、所选子项和范围外清单均保留。
- 没有上传/持久化读回、学生历史、实机手写或实时做题页面验收。当前验收目标是 agent 能独立生成正确结构、保真图像和可预检的导入文件。
