# 全局通知规则与接入清单

## 统一体验

桌面端右上角；窄屏贴近顶部，左右留白。使用半透明背景、圆角、柔和阴影和轻量动效。普通操作提示与持久通知共用 Sonner 栈，最多显示 3 条；持久任务横幅逐条展示。成功 6.5 秒、需处理事项 10 秒，悬停暂停，支持键盘和减少动态效果。

铃铛和 `/notifications` 共用通知记录。关闭、超时仅收起横幅；查看详情或显式标记才算已读。按事件 ID 去重；首次加载历史任务不补弹。最近 50 条按账号保存在当前浏览器，刷新恢复，不重播。尚未提供服务端收件箱、跨设备同步、离线推送或系统级浏览器通知。

## 统一接入约束

所有自动弹出的操作结果、校验失败、错误、奖励与任务提醒使用 `@/lib/notifications/client-toast`，由根布局唯一的 Toaster 展示。禁止浏览器 `alert`、`toast.custom` 或业务代码直接导入 Sonner toast；旧 NotificationBannerCard 仅用于样式对比预览，不再用于业务弹出。

题目提交由提交处理函数统一提示一次；提交成功不代表答案正确，判分和解析保留在题目及提交历史中。旧笔记本题库的鼓励记录仅进入通知历史，不重复弹出。抽卡结果用轻提示，全部奖励明细留在补给站；生成角色后用轻提示并继续生成，用户可主动查看角色详情。

用于输入、编辑、查看详情以及删除/付款确认的对话框仍承载相应交互，不属于自动结果通知。

## 哪些需要通知

| 场景 | 提醒规则 | 当前接入状态 |
| --- | --- | --- |
| 上传题库、讲义后的后台解析 | 完成、失败、需要确认时弹窗并留存；跳转课程工作区 | 已接教师任务状态变化；首次打开仅建立基线 |
| 队列中的图片、视频、课件、复习路线、幻灯片修复 | 完成/失败弹窗并留存，查看跳转原任务页面 | 已接共享 AI 任务历史状态变化 |
| 持久课堂讲解生成 | 完成/失败弹窗并留存 | 已接全局后台轮询；仍需页面/任务注册保持跟踪 |
| AI 正在生成、队列排队 | header 光带、任务百分比、队列角标；不逐秒弹通知 | 沿用已有任务反馈 |
| 普通聊天回复、语音、逐题判分 | 留在对话/题目中；主动题目提交统一短提示一次，失败用轻量错误提示，不额外发完成横幅 | 已排除高频任务自动结果通知 |
| 上传格式不支持、文件过大 | 立即提示如何修改，不进入长期收件箱 | 现有操作提示统一视觉 |
| 保存、复制、下载、导出、发布 | 用户主动操作后短提示；自动保存不提示 | 现有 Sonner 操作统一视觉 |
| 充值到账、购买成功、奖励到账 | 需要凭证的结果留存；普通每次 token 扣费仅账单 | 现有调用保留；服务端到账主动通知待接入 |
| 余额不足、权限过期、登录失效 | 在操作受阻时提醒并给处理入口；相同原因应合并 | 现有错误提示保留；统一业务事件与去重待接入 |
| 作业发布、截止提醒、批改完成、老师公告 | 留存并链接具体课程/作业；允许设置提醒偏好 | 待服务端事件与收件箱接入，不模拟触发 |
| 网络断开/恢复 | 持续异常再提示；恢复只在之前报告断开时提示 | 待接入，避免将单次请求失败判断为断网 |
| 删除、覆盖、付款前确认 | 使用操作内确认对话框；通知不能替代确认 | 保留原确认流程 |
| 页面切换、打开菜单、自动同步、重试中间步骤 | 无通知 | 不新增 |

## 代码入口

- 普通即时反馈：`lib/notifications/client-toast.ts`，兼容现有 toast、loading、promise、dismiss 调用。
- 持久通知：`useNotificationStore.enqueueBanner`；需提供稳定的事件 ID、清晰标题、可公开描述以及可选 `href`。
- AI 结果：`lib/notifications/task-notifications.ts`，仅真实终态触发，不通过光带熄灭推断成功。不展示原始异常堆栈。
- 全局展示：根布局 Toaster 与 NotificationCenterProvider，路由切换不销毁整个通知栈。
- 视觉预览：`/qa/notifications`，仅展示样例弹窗，不写入用户历史。

后续服务端收件箱应以接收者 ID + 事件 ID 幂等写入，并在服务端校验身份。需要支持分页、已读同步、保留期限和按类型偏好，才能可靠覆盖离线期间完成的任务与跨设备通知。
