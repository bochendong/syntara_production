# Class standing illustrations

40 original illustrations approved in the 2026-11-05 design session. Generated with the built-in ImageGen tool in graphite, colored pencil and watercolor style. Each scene uses a different Chinese international university student or group and is independent of the others.

The approved PNG artwork is exported to 768 × 1152 WebP at quality 86 for bundled App use. Original PNGs and full generation prompts remain in the design delivery package `quote-series-complete.zip`.

Quotes, source links, Chinese scene descriptions and eligible learning states are maintained in `../../components/problem-bank/class-standing-art.ts`. Foreign quotations are translated from the linked originals, not attributed to a named Chinese publication. The card typesets quotations separately for legibility and accessibility.

Run the offline catalog and rotation check from the repository root:

```sh
node --experimental-strip-types scripts/maintenance/verify-class-standing-art.mjs
```
