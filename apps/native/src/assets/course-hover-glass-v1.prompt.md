# Course sidebar hover artwork

Generated with the built-in ImageGen tool, with transparent background enabled.
Asset: `apps/native/src/assets/course-hover-glass-v1.png`.
The neutral glass texture is composited over the existing scene matching each row's resolved course avatar; catalog colors come from the same avatar palette used by the store. Custom avatars supply their own image as the backdrop. Text and controls stay above the fading artwork.

## Final generation prompt

Create a production UI raster texture, landscape 3:1 composition, for a very small horizontal course-row hover background in a refined learning app. This is ONLY a transparent glass-light overlay, NOT an interface mockup. On a genuinely transparent alpha background, paint two extremely delicate frosted white / pale silver refractive caustic ribbons and a soft luminous bloom concentrated near x=8%, y=50%, where a round marble avatar will sit. The caustic ribbons gently fan horizontally toward the right and dissolve to fully transparent by x=65%. Leave the right third empty and transparent for readable labels and buttons. Elegant liquid-glass material, fine soft grain, subtle organic refraction, restrained contrast, no sharp spikes, no saturated colors, no dark outline, no opaque rectangle, no frame, no text, no letters, no icons, no sphere or avatar drawn. It will be composited over each avatar's own colored landscape so it must be neutral and versatile. Deliver a single isolated transparent texture asset.
